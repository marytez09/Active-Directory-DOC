# Active Directory & Lab Project
## Description

This lab simulates real life IT environments through a virtual machine. Utilizing Windows Server 2022, and Windows 10 Pro, demonstrating a centralized server domain from which users are created and able to use through client machines. This documentation goes over the full step-by-step process of making an Active Directory from scratch, including screenshots and troubleshooting issues from root problems to fixes.

## Purpose

The purpose of this lab was to learn the fundamentals of building and troubleshooting in gaining hands-on experience with creating users and groups within an Active Directory, configuring permissions and security protocols, file sharing, troubleshooting networks, and Powershell. 

## Skills Demonstrated
- Installing Operating Systems
- Virtualization 
- Active Directory
- Group Policy Management (GPO)
- User Management
- File Share
- DNS
- DHCP
- TCP/IP
- Powershell

## Lab Environment
- Oracle VirtualBox
- Windows Server 2022
- Windows 10 Pro
